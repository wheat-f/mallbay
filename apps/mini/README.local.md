# MallBay 小程序本地联调说明

本文档用于本地开发、微信开发者工具和真机调试。不得在本文档中写入真实 AppID、AppSecret、JWT、OSS 密钥、测试账号密码或内网穿透地址。

## 1. 导入项目

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择仓库内 `apps/mini`。
4. AppID 使用个人或团队提供的测试 AppID；没有 AppID 时仅可使用开发者工具的测试号能力。
5. 项目名称可填写 `MallBay Mini Dev`。

## 2. 本地 API 地址

开发者工具模拟器访问本机 API 时，优先使用：

```text
http://localhost:3001
```

真机访问本机 API 时，`localhost` 指向手机本身，不能直接访问电脑服务。必须选择以下任一方式：

- 使用同一局域网可访问的电脑 IP，例如 `http://192.168.x.x:3001`，仅用于开发者工具允许 HTTP 的本地调试场景。
- 使用 HTTPS 内网穿透地址，并在微信公众平台配置为合法 request 域名。
- 使用部署到测试环境的 HTTPS API 地址。

所有本地 API 地址都应通过小程序“连接配置”页面写入本机存储，不提交到 Git。

## 3. 微信平台配置

真机联调前必须在微信公众平台确认：

- request 合法域名包含当前 API HTTPS 域名。
- uploadFile 合法域名包含 OSS 或本地上传代理 HTTPS 域名。
- AppID 与 API 环境变量 `WECHAT_MINI_APP_ID` 一致。
- AppSecret 只配置在 API 本地环境或部署环境中，不写入小程序代码。

## 4. 登录调试

推荐流程：

1. 在 API 环境中配置 `WECHAT_MINI_APP_ID` 和 `WECHAT_MINI_APP_SECRET`。
2. 确认测试用户已绑定微信 openId，或准备好账号绑定流程。
3. 在小程序“连接配置”页填写 API 地址。
4. 点击微信登录，成功后页面会保存 access token 和门店 ID。
5. 进入任务页执行“同步任务”。

临时调试流程：

1. 通过 Web 或 API 获取测试 JWT。
2. 在小程序“连接配置”页手动填写 API 地址、access token 和门店 ID。
3. 进入任务页执行“同步任务”。

临时 JWT 只能保存在微信开发者工具或真机本地存储，不得写入源码、截图文档或提交记录。

## 5. 真机断网验收

执行前置条件：

- 测试账号拥有施工人员或学徒身份。
- 测试门店存在已派工订单。
- 任务页已经成功同步过任务。

验收步骤：

1. 打开任务详情。
2. 关闭手机网络。
3. 点击开工，确认离线队列新增施工状态记录。
4. 拍摄施工前照片，确认离线队列新增照片记录。
5. 提交请假，确认离线队列新增请假记录。
6. 恢复网络。
7. 进入离线队列页点击同步。
8. 确认成功项从队列移除，失败项保留并累计重试次数。

## 6. 不入库清单

以下内容 MUST NOT 提交到 Git：

- 微信 AppID、AppSecret。
- JWT access token、refresh token。
- 真实测试账号、手机号、密码。
- OSS AccessKey、Bucket、Endpoint。
- 内网穿透 URL、局域网 IP。
- 微信开发者工具生成的本机私有配置。
