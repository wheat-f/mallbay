# Bootstrap a single headquarters administrator

总部权限本轮采用单一初始化账号承载：权限迁移脚本优先读取 `HQ_ADMIN_USERNAME`，未配置时按 `zhouluoren` → `xiaoming` 顺序选择首个已存在账号，幂等补齐一个 `HQ_ADMIN/HQ` 绑定；脚本不读取密码、不负责创建账号或重置密码，目标账号不存在时直接失败。这样可以让总部治理入口有确定的责任主体，避免旧审核员标记意外扩大总部权限，同时保留该账号已有的门店角色绑定。

## Status

accepted

## Consequences

- `isAuditor` 不再是新的总部授权来源，遗留代码必须逐步迁移到有效的 `HQ_ADMIN/HQ` 权限判断。
- 迁移脚本优先使用 `HQ_ADMIN_USERNAME`；未配置时按 `zhouluoren` → `xiaoming` 顺序选取已存在账号；目标账号必须由账号/种子流程预先创建，脚本不保存、生成或重置密码。
- 迁移脚本必须可重复执行，不重复创建用户、角色或绑定，也不能覆盖目标账号密码和既有门店成员关系；发现其他有效总部绑定时必须失败并保持数据不变。
- 总部成员绑定能力暂时只能由迁移脚本完成；页面和公开写接口必须拒绝新增、修改或停用其他人员的总部绑定。
