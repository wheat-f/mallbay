# Phase 6 微信小程序真机验收脚本

- 文档类型：验收说明
- 文档状态：初版
- 适用范围：师傅端任务、离线开工、离线完工、施工拍照、离线请假、微信登录
- 来源依据：[Phase 6 微信小程序联调与发布实施计划](./phase-6-mini-program-integration-plan.md)

## 前置条件

MUST：

- API 已启动，并可通过开发者工具或真机访问。
- 测试账号已绑定微信 openId，或已准备临时 JWT 调试 token。
- 测试账号在测试门店中拥有施工人员或学徒身份。
- 测试门店存在至少一个已派工订单，且当前测试账号是派工人员之一。
- 小程序连接配置页已保存 API 地址和门店 ID。

MUST NOT：

- 不使用生产账号、生产订单或生产 OSS 密钥做开发验收。
- 不在验收截图中暴露 JWT、AppSecret、手机号、车牌完整号码或客户隐私。

## 开发者工具可验收项

### A1：连接配置保存

步骤：

1. 打开 `apps/mini`。
2. 进入“连接配置”页。
3. 输入 API 地址、access token 和门店 ID。
4. 点击保存。
5. 关闭并重新打开页面。

预期结果：

- 页面回显上次保存的 API 地址和门店 ID。
- token 不应出现在控制台错误日志中。

### A2：任务同步

步骤：

1. 进入任务列表页。
2. 点击同步任务。
3. 等待请求完成。

预期结果：

- 有派工任务时，列表展示订单、客户、车辆、预约时间和施工状态。
- 后端返回 `{ items: [...] }` 或数组响应时都能正常写入本地缓存。
- 无任务时显示空状态，不报错。

### A3：离线队列状态入队

步骤：

1. 打开一个已派工任务详情。
2. 关闭开发者工具网络或临时断开 API。
3. 点击开工。
4. 返回离线队列页。

预期结果：

- 离线队列新增 `TASK_STATUS` 记录。
- 开工记录包含本地 `startedAt`。
- 页面提示进入待同步状态。

### A4：离线拍照入队

步骤：

1. 打开任务详情。
2. 选择施工前照片。
3. 返回离线队列页。

预期结果：

- 离线队列新增 `PHOTO_UPLOAD` 记录。
- 照片记录包含本地文件路径、阶段和 `takenAt`。

### A5：离线请假入队

步骤：

1. 进入请假页。
2. 选择开始日期和结束日期。
3. 输入请假原因。
4. 提交。
5. 返回离线队列页。

预期结果：

- 离线队列新增 `LEAVE_REQUEST` 记录。
- 日期和原因展示正确。

## 真机必须验收项

### M1：微信 code 登录

步骤：

1. API 环境配置 `WECHAT_MINI_APP_ID` 和 `WECHAT_MINI_APP_SECRET`。
2. 确认微信 openId 已绑定测试用户。
3. 真机打开小程序。
4. 进入连接配置页，仅填写 API 地址。
5. 点击微信登录。

预期结果：

- 登录成功后保存 access token 和门店 ID。
- 任务页可直接同步当前施工人员任务。
- 配置缺失时返回“微信小程序登录未配置”，不出现“服务器内部错误”。

### M2：真机断网施工记录

步骤：

1. 真机同步任务。
2. 打开任务详情。
3. 打开飞行模式或关闭网络。
4. 点击开工。
5. 拍摄施工前照片。
6. 点击完工。

预期结果：

- 开工、照片、完工都进入离线队列。
- 开工记录包含 `startedAt`。
- 完工记录包含 `completedAt`。
- 照片记录包含 `takenAt`。
- 队列达到 100 条时，继续入队会提示“本地缓存已达上限，请联网同步后再继续操作”。

### M3：真机恢复网络同步

步骤：

1. 保持 M2 的离线队列数据。
2. 恢复网络。
3. 进入离线队列页。
4. 点击同步。

预期结果：

- 成功项从队列移除。
- 单条失败不阻断后续记录。
- 失败记录在 3 次以内保持待同步。
- 第 3 次失败后标记为同步失败。
- 后端施工记录可追溯开工、完工、照片阶段和拍摄时间。

### M4：权限边界

步骤：

1. 使用未被派工的施工人员账号登录。
2. 尝试同步其它师傅的任务。
3. 尝试同步其它师傅任务的开工、完工或照片。

预期结果：

- 任务列表不展示未指派任务。
- 同步其它师傅任务的操作被 API 拒绝。
- 错误项在离线队列中保留并累计重试次数，不影响其它合法项。

## 失败排查

- 登录返回“微信小程序登录未配置”：检查 API 环境变量 `WECHAT_MINI_APP_ID` 和 `WECHAT_MINI_APP_SECRET`。
- 真机无法请求 API：检查 HTTPS、合法 request 域名和真机可访问地址。
- 上传照片失败：检查 uploadFile 合法域名、OSS 本地服务或上传代理。
- 任务列表为空：检查当前用户是否属于施工人员或学徒，且是否被派工到测试订单。
- 离线同步一直失败：检查 access token 是否过期、门店 ID 是否正确、任务是否仍属于当前用户。
