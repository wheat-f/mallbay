# 产品建议价与施工收费操作手册

- 文档类型：门店操作手册
- 文档状态：现行版本（2026-07-17）
- 适用范围：门店店长、财务、销售使用建议价、施工收费、标准工时及订单试算
- 来源依据：当前页面 `/orders/pricing`、`/orders/pricing/construction-costs`、`/orders/create` 的实际交互与服务端校验
- 配套说明：[产品建议价与施工收费功能介绍及使用场景](./sales-order-pricing-and-construction-charge-guide.md)

## 1. 使用前检查

开始维护前，门店必须确认以下基础信息可用：

1. 产品档案已填写品牌、类别、销售单位和基础销售价。
2. 需要核算成本的产品已具备入库批次成本或产品标准成本。
3. 施工地点、施工类型、产品分类、销售单位、施工岗位等系统字典项已存在且使用中文业务名称。
4. 店长已具备门店管理权限；财务已具备岗位成本维护权限。

**MUST：** 字典中不存在的选项，先由系统字典维护流程补齐，不能在规则页面手写临时编码。\
**MUST NOT：** 将产品价格、施工收费、岗位小时成本或审批阈值作为普通字典项维护。

## 3. 店长：维护产品建议价规则

### 3.1 创建草稿

1. 打开“建议价设置”。
2. 若没有正在编辑的版本，点击“开始设置建议价”或“编辑当前建议价”。
3. 确认草稿的生效日期；已发布版本不可直接修改。
4. 进入“产品建议价规则”页签。

### 3.2 新增一条产品价格规则

1. 点击“添加规则”。
2. 在“当”中选择条件字段，例如“产品分类”“产品品牌”“施工地点”或“车型级别”。
3. 系统会按字段类型提供合适的比较方式：
   - 分类、品牌、地点、单位、车型级别：使用“为”或“属于”。
   - 数量、年份：使用“介于”“不少于”“不超过”。
4. 从下拉选项中选择条件值。
5. 在“将”中确认目标为“产品建议价”，选择加价、优惠或比例调整并填写金额/比例。
6. 查看规则预览的自然语言，确认其业务含义无误。
7. 保存草稿。

**示例：** “当产品品牌为‘改装品牌1’时，将产品建议价加价 ¥1,000”。

### 3.3 冲突处理

若保存或发布提示规则冲突：

1. 不要新增一条同条件但金额不同的规则。
2. 判断两条规则是否应为同一条；若是，保留正确金额并删除重复项。
3. 若确实针对不同业务条件，补充可区分条件，例如施工地点、品牌、销售单位或数量区间。
4. 不要通过更换“规则名称”或拆分到不同展示项绕过冲突校验。

## 4. 店长：维护施工服务项目

施工收费标准首页点击“维护服务项目”。先完成此步骤，施工标准中才可选择服务项目。

1. 填写唯一的项目编码，例如 `PPF_FULL`；编码仅供系统识别。
2. 填写对业务人员展示的中文项目名称，例如“全车漆面保护膜”。
3. 从系统字典选择施工类型。
4. 填写施工组名称。相同施工流程的服务项目必须使用同一施工组。
5. 可选填默认产品分类，用于缩小适用范围。
6. 点击“添加服务项目”，确认下方列表状态为“启用”。

**RECOMMENDED：** 施工组使用稳定、易懂的中文业务名称，例如“全车漆面保护膜”，避免把临时价格或人员名称写入施工组。

## 5. 财务：维护岗位小时成本

施工收费标准首页点击“维护岗位成本”。岗位小时成本是内部成本，不是对客施工收费。

1. 新建成本版本，填写生效日期；如有明确结束日期可填写，否则留空。
2. 为将要出现在施工班组中的每个岗位，选择系统字典岗位并填写“小时成本（元）”。
3. 保存为成本草稿，复核岗位覆盖范围和金额。
4. 点击“核对后发布”。发布后不能直接修改；如发生调薪，请新建下一版本。
5. 通知店长在施工标准中选择该已发布版本。

**MUST：** 施工标准班组中出现的岗位，必须在所选成本版本中有小时成本。\
**MUST NOT：** 通过修改已发布成本版本追溯影响历史订单。

## 6. 店长：维护施工收费与标准工时

施工收费标准首页点击“维护施工标准”。若页面提示没有可编辑草稿，先返回“建议价设置”创建/编辑草稿。

### 6.1 新建主标准

1. 选择财务已发布的“岗位小时成本版本”。
2. 选择唯一的“主施工项目”。
3. 选择施工地点；按需选择车型级别、产品分类、销售单位和数量区间。
4. 填写主项目收费和主项目标准工时。
5. 填写追加项目收费和追加项目工时；没有追加量时填 `0`。
6. 填写标准提成、标准补贴（如适用）。
7. 在“施工班组与岗位工时”中逐行选择岗位、人数和每人标准工时。
8. 点击“保存施工标准到草稿”。

### 6.2 如何配置“主项目 + 追加量”

对于同一施工组的 3 个产品，不建立 3 条同范围规则。只建立 1 条主标准：

```text
主项目收费：¥1,800
每个追加项目收费：¥300
主项目标准工时：240 分钟
每个追加项目工时：30 分钟

订单有 3 个同组产品：
施工收费 = 1,800 + (3 - 1) × 300 = ¥2,400
标准工时 = 240 + (3 - 1) × 30 = 300 分钟
```

当收费真正需要按数量分段时，增加互不重叠的区间，例如 `1–2` 与 `3–5`。不要为“第 2 个产品”“第 3 个产品”各建一条相同适用范围的标准。

### 6.3 发布与试运行

1. 保存施工标准后，点击“进入发布与试运行”，返回建议价设置。
2. 先执行“检查规则和冲突”。有冲突必须修改草稿，不可强行发布。
3. 使用“试算工具”输入典型客户车辆、产品和施工条件，核对产品建议价、系统建议施工收费和预计成本。
4. 先选择观察试运行（SHADOW），用实际样例订单核对差异。
5. 预检通过并确认无业务差异后，执行“确认发布并生效”，再按门店发布流程切换正式启用（ACTIVE）。

## 7. 销售：新建订单并采用建议价

1. 新建销售订单，选择客户、车辆、预约日期、施工地点和产品。
2. 确认每个产品行显示正确的销售单位；按卷、米等单位分别录入数量。
3. 等待服务端完成试算：产品行会展示建议单价，施工区会展示“系统建议施工收费”。
4. 如认可建议，点击产品行“采用建议价”，并点击本单施工收费旁的“采用建议价”。
5. 如客户议价，可直接修改产品成交单价或“本单施工收费”。若与系统建议不一致，必须填写“施工收费调整原因”。
6. 保存草稿或提交订单。系统会按偏差、最低保护价及预计毛利执行正常、需审批或禁止提交的判定。

### 7.1 订单金额怎么看

- “系统建议施工收费”不可编辑，是计算参考。
- “本单施工收费”是订单最终对客户收取的金额。
- 销售不显示具体内部成本、预计毛利金额；店长可查看内部成本与毛利区。
- 正式订单和已批准报价会冻结价格与成本快照，后续规则变化不改写历史单据。

## 8. 店长：处理成本缺失与临时成本

当页面显示“待维护材料成本”“待维护施工标准”或“成本状态：待补齐”时：

1. 先检查产品是否有库存批次成本、近期入库成本或产品标准成本。
2. 检查是否存在能匹配当前施工地点、车型级别、产品分类、销售单位和数量的已发布施工标准。
3. 优先补齐产品成本或施工标准后，重新试算。
4. 如确因当单特殊情况无法维护标准，店长填写“本单临时预计成本”和“临时成本依据”。
5. 临时成本订单必须走报价审批；批准后预计成本冻结为该订单快照。

**MUST NOT：** 把缺失成本当作零成本处理，也不能通过填写本单施工收费替代内部成本。

## 9. 常见问题与处理

| 现象 | 常见原因 | 处理方式 |
|---|---|---|
| 没有“系统建议施工收费” | 没有匹配已发布施工标准 | 补齐服务项目、施工标准、岗位成本版本或调整适用范围 |
| 预计材料成本显示“待维护” | 产品无库存/入库/标准成本来源 | 补录库存批次成本或产品标准成本；必要时走临时成本审批 |
| 预计施工成本显示“待维护施工标准” | 当前产品/地点/单位/车型未命中标准 | 检查施工组、地点、分类、单位、数量区间及岗位成本版本 |
| 规则无法保存 | 条件重复或范围重叠 | 合并为一条规则，或增加有效区分条件；数量区间不得重叠 |
| 施工标准提示同组冲突 | 同组、同适用范围建了多条主标准 | 保留一条主标准，用追加收费/工时表示后续产品 |
| 本单施工收费改完要求原因 | 与系统建议不一致 | 如实填写车型复杂、外出、客户特批等业务依据 |
| 已发布规则无法编辑 | 版本冻结 | 创建新草稿版本，发布后仅影响新订单 |
| 销售看不到成本金额 | 角色权限控制 | 由店长/财务核对内部成本；销售只处理报价结果 |

## 10. 发布前检查清单

- [ ] 产品档案、销售单位和基础销售价完整。
- [ ] 相关产品有可用材料成本来源。
- [ ] 施工服务项目与施工组已维护且启用。
- [ ] 财务已发布覆盖班组岗位的小时成本版本。
- [ ] 店长已配置主项目、追加量、标准工时和班组。
- [ ] 同施工组施工标准无重叠，数量分段不重叠。
- [ ] 产品建议价规则无冲突，且只调整产品建议价。
- [ ] 用典型订单在试算工具完成核对。
- [ ] 先完成 SHADOW 观察，再由授权人员发布 ACTIVE。
- [ ] 已向销售说明“系统建议施工收费”和“本单施工收费”的区别。

## 11. 日常维护建议

- **每次新产品/新服务上线前：** 店长和财务共同补齐产品成本、服务项目、施工标准和岗位成本版本。
- **每次价格策略调整：** 店长新建建议价草稿，先试算再发布，保留旧版本用于历史追溯。
- **每次岗位成本变化：** 财务新建成本版本；店长确认新版本与施工标准的班组岗位完整匹配。
- **每周：** 店长复核“待补齐成本”的草稿和报价，避免长期依赖临时成本。
- **每月：** 财务核对预计与实际施工成本差异，并对异常成本调整和结算记录进行审计。
