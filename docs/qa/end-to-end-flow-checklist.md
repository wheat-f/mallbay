## 结果判定

- [ ] 三个场景均可通过页面完成，不修改数据库数据。
- [ ] 重复点击已完成操作不会产生重复记录。
- [ ] 页面刷新后状态、照片、草稿和处理记录仍然存在。
- [ ] 店长和施工人员只看到自己的操作入口。
- [ ] 所有失败请求显示明确业务原因，并且不会留下半成品状态。
