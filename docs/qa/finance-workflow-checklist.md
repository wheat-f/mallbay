# 财务工作流验收清单

## 目标

验证费用申请、报销申请、审批、付款、附件和资金流水能够形成可追溯闭环，并且不同角色只看到自己有权限执行的动作。

## 费用申请

- [ ] 申请人可以在“费用申请”列表新建申请，提交后状态为“待部门审批”。
- [ ] 列表可以按申请编号、状态、申请类型和日期范围查询，并能进入详情。
- [ ] 申请人在部门审批前可以撤回；撤回后可重新提交，审批历史保留。
- [ ] 部门主管只能处理自己门店或授权范围内的申请。
- [ ] 审批通过后进入财务审批；驳回时必须填写原因，并在详情和审批历史中可见。
- [ ] 申请详情显示当前节点、审批时间线、附件和允许操作；已完成节点不重复显示可执行按钮。

## 报销与付款

- [ ] 报销申请与费用申请分开列表展示，报销详情可以查看关联费用、金额和附件。
- [ ] 财务审批通过后才能登记付款；付款必须选择有效收款账户。
- [ ] 同一报销单重复点击付款不会生成重复付款记录或重复支出流水。
- [ ] 付款完成后报销状态、付款时间、付款账户和流水编号立即刷新。
- [ ] 被驳回的报销可以按规则重新提交，重新提交后回到正确审批节点。

## 附件与审计

- [ ] 费用申请和报销申请均支持上传多个附件，并在详情页预览或下载。
- [ ] 附件按业务对象关联，不能通过修改请求参数访问其他申请的附件。
- [ ] 创建、撤回、重新提交、审批、驳回和付款均产生审批历史或资金流水记录。

## 账户与流水

- [ ] 收款账户列表仅展示当前门店可用账户，并能进入账户详情。
- [ ] 财务流水按收入/支出、业务类型、账户和日期范围筛选。
- [ ] 费用付款生成“支出”流水；金额、方向、账户、业务单号和发生时间一致。
- [ ] 无权限角色不能执行审批、付款、账户维护或跨门店查询。
