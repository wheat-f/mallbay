# 系统设置职责工作台实施证据（2026-07-28）

## 已落地

- `GET /settings/capabilities`：服务端按角色、能力、操作、门店范围返回可见能力；总部审核员对门店配置只读，店长/财务不能跨店。
- 配置版本 API：草稿创建、服务端校验、版本冲突、发布、已发布不可直接修改、审计事件。
- 设置首页：按 HQ/STORE/FINANCE/OWN 分组加载“我的职责”，规划中能力不可点击，403/加载失败有明确反馈。
- 字典：大类/小类展示、逐项启停、版本号、引用计数保护、总部禁用提示、服务端回读和字典审计。
- 审计：分页查询、当前门店范围过滤、总部全局查看、安全导出与敏感字段脱敏、超过 10,000 条拒绝。
- 财务职责入口：岗位小时成本版本和收款账户读取现有服务端能力，并链接到实际维护页。
