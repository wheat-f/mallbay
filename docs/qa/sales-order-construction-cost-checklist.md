## 2. 订单与报价验收

| 场景 | 操作 | 期望结果 |
|---|---|---|
| 完整成本订单 | 选择产品、车辆、施工地点后试算 | 显示建议产品价、系统建议施工收费、预计材料/施工/总成本和预计毛利；预计成本不可编辑 |
| 本单改价 | 修改成交单价或本单施工收费 | 显示调整原因；按产品、施工收费、整单、保护价和毛利取最严格审批结果 |
| 缺失成本 | 缺少材料或施工标准后尝试提交 | 不可直接生成正式订单；店长可填写本单临时成本及依据，必须生成报价审批 |
| 临时成本转单 | 批准临时成本报价后转正式订单 | 正式订单冻结临时成本、依据、价格快照和审批结果 |
| 草稿重算 | 打开含价格快照的本地草稿 | 可选择沿用草稿规则或按当前发布规则重算 |
| 正式冻结 | 尝试修改带价格快照的正式订单商业字段 | 服务端拒绝原地修改 |

## 3. 施工成本验收

| 场景 | 操作 | 期望结果 |
|---|---|---|
| 完工初始化 | 完成施工记录 | 创建待确认成本结算，标准工时与岗位小时成本来自订单快照 |
| 工时偏差 | 施工人员申报偏差 | 标记异常，店长必须逐单确认 |
| 正常批量确认 | 选择无偏差、成本完整任务 | 支持批量确认 |
| 实际材料成本 | 完成订单出库和施工损耗后确认成本 | 按 `ORDER_OUT`、`DAMAGE_OUT` 批次、数量和单位成本计算并冻结明细 |
| 实际个人提成 | 财务维护师傅实际提成后确认成本 | 结算读取佣金模块的 `finalAmountCents`，不信任页面传入金额 |
| 调整和冻结 | 确认后创建调整单并财务结算 | 确认后只能走调整单；结算后不允许覆盖 |

## 4. 权限与导出验收

- [x] 销售仅可看到订单和报价审批结果，无法读取预计成本、临时成本、实际成本或毛利字段。
- [x] 店长、财务、管理员可查看内部成本；店长可维护施工标准、确认成本；财务维护岗位费率并结算。
- [x] 店长成本确认接口和导出只提供工时与订单级汇总，不返回个人岗位小时成本、提成或补贴；财务/管理员保留核算明细。
- [x] 销售订单导出为服务端全量、逐产品行，支持客户/日期/产品排序；成本列仅授权角色存在。
- [x] 采购订单导出为服务端全量、逐产品行，支持供应商/日期/产品排序。
- [x] 报价与施工成本导出均使用统一 Excel 模板；金额单位为元、毛利率为百分比。

## 5. 灰度与回滚

1. 新门店先设为 `LEGACY`，核对历史订单仅保留收入语义。
2. 配置并发布施工标准、岗位费率、保护策略后切入 `SHADOW`；记录新旧建议价与成本差异。
3. 差异解释完成且预检通过后切入 `ACTIVE`。
4. 若发生业务异常，将门店切回 `LEGACY` 或 `SHADOW`；不得删除已生成的报价、订单、成本结算、调整或审计快照。
5. 回滚只改变新订单的运行模式；已批准报价、正式订单及已结算成本继续按其冻结快照展示。
