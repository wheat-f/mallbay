# 销售订单智能建议价与价格审批验收清单

## 自动化回归

- [x] 价格引擎固定顺序、同组择一、跨组叠加。
- [x] 产品行、人工费、总价和预计毛利取最严格结果。
- [x] 成本估算按库存加权平均、最近入库、标准成本、缺失成本顺序。
- [x] 车辆映射支持优先级、年份范围、冲突检测、批量导入和未识别车型。
- [x] 价格试算按车辆自动匹配价格级别；手动修正仅作用于本单并进入服务端快照。
- [x] 报价批准、驳回、撤回、重算、过期和容量释放。
- [x] 订单快照复核，报价转订单状态保护。
- [x] 新建订单建议价只读，成交价可修改且不被重算覆盖。
- [x] 产品销售单位独立列展示，草稿可保存和恢复。
- [x] 恢复含价格快照的草稿时可选择沿用原规则或按最新规则重算。
- [x] 卷、米、平方米成本换算与单位精度校验。
- [x] 米/平方米产品支持最多 3 位小数数量入单和报价转单。
- [x] 小数数量乘单价统一半入舍入为整数分，建议价、报价和正式订单金额口径一致。
- [x] SHADOW 模式记录新旧建议价差异，模拟器展示逐条计算步骤。
- [x] 容量返回并展示报价软占位与正式预约来源。
- [x] 直接新建预约订单写入 ORDER/CONFIRMED 明细，容量条件更新在并发满额时拒绝超卖。
- [x] 带价格快照的正式订单拒绝后续产品清单、成交价和人工费修改。
- [x] 系统固定字典禁止新增、删除和停用，业务字典提供默认项。
- [x] 规则、报价、容量、模板和灰度关键动作输出结构化审计事件并持久化到 `AuditEvent`。

## 人工验收场景

1. 选择不同产品、车辆级别、施工类型和地点，确认建议产品价、人工费和总价随服务端规则变化。
2. 手动修改产品或人工费，重新触发试算，确认成交价保留并出现建议价变化提示。
3. 低于产品保护价、人工保护价或预计毛利底线，确认无法直接建正式订单并转报价审批。
4. 店长批准报价后转正式订单，重复点击转单不得生成第二张订单。
5. 报价撤回、驳回、超时后，确认容量占位释放且每日容量计数恢复。
6. 在容量页面确认 QUOTE/HELD 与 ORDER/CONFIRMED 来源可区分。
7. 总部发布模板，门店复制后修改，确认总部后续更新不覆盖门店规则。
8. 将门店切换到 LEGACY、SHADOW、ACTIVE，确认切换可审计且历史订单不重算。
